### Booking CRM API

Простая и эффективная CRM-система для бронирования заказов (столиков, комнат или номеров в отелях). Проект предоставляет готовый REST API с базовым функционалом управления бронированиями, пользователями и инвентарем. 

### 🛠 Технологический стек

- **Фреймворк:** [FastAPI](https://fastapi.tiangolo.com/)
- **ORM:** [SQLAlchemy](https://www.sqlalchemy.org/) (с поддержкой асинхронности)
- **База данных:** [PostgreSQL](https://www.postgresql.org/)
- **Миграции:** [Alembic](https://alembic.sqlalchemy.org/)
- **Авторизация:** JWT (кастомная реализация через [PyJWT](https://pyjwt.readthedocs.io/))

### 🚀 Основной функционал

- Аутентификация и авторизация пользователей на основе JWT-токенов.
- Управление сущностями бронирования (создание, чтение, обновление, удаление).
- Контроль статусов бронирования (комнаты / столики).
- Автоматическая генерация интерактивной документации.

### ⚙️ Установка и запуск

### 1. Клонирование репозитория

```bash

git clone https://github.com/DarkMonarch-DN/Booking_CRM.git
cd booking_crm
```

### 2. Настройка виртуального окружения

```bash
poetry init
```

### 3. Установка зависимостей

```bash

poetry install
```

### 4. Настройка переменных окружения

Создайте файл .env в корневом каталоге проекта по образцу: 

```env
DB_USER = "postgres"
DB_PASS = "postgres"
DB_HOST = "localhost"
DB_PORT = 5432
DB_NAME = "crm"

JWT_SECRET = "super_secret_key"
JWT_ALGORITHM = "HS256"
JWT_EXPIRE_MINUTES = 90
```

### 5. Применение миграций базы данных

```bash

alembic upgrade head
```

### 6. Запуск сервера

```bash

uvicorn app.main:app --reload
```

После запуска сервер будет доступен по адресу: http://127.0.0.1:8000 

### 📖 Документация API

Проект поддерживает автоматическую генерацию документации. После запуска сервера вы можете изучить все эндпоинты, их параметры и схемы запросов: 

- **Swagger UI (Интерактивный интерфейс):** http://127.0.0.1:8000/docs
- **ReDoc (Альтернативный вид):** http://127.0.0.1:8000/redoc
